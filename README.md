# 경제정책 시뮬레이터

고등학교 경제 PBL 수행평가용 웹앱입니다. 학생이 정부·한국은행의 경제정책 조정회의 위원이 되어, 위기 상황(스태그플레이션, 경기 침체, 집값 거품, 환율 급등)을 8분기 동안 정책으로 해결합니다.

- 기준금리, 공개시장조작, 외환시장 개입, 정부지출, 세율을 슬라이더로 조절
- 특별 대책(에너지 바우처, 고용 지원, 공급망 투자, 관세 인하, 대출 규제, 통화스와프) 토글
- 슬라이더를 움직이면 다음 분기 예상치가 그래프에 점선으로 표시
- 문제 진단 → 분기별 결정과 근거 → 성찰 → 보고서(텍스트 복사 제출)

단일 `index.html` 정적 페이지이며 Vercel에 그대로 배포됩니다. 모형은 교육용으로 단순화한 것입니다.

## 구글 시트 저장 설정
1. 새 구글 시트 → [확장 프로그램] > [Apps Script]에 `apps-script/Code.gs` 내용을 붙여 넣고 저장
2. [배포] > [새 배포] > 유형 **웹 앱**, 실행 **나**, 액세스 **모든 사용자** → 배포 후 웹 앱 URL 복사
3. `index.html`의 `const SHEET_URL = '';`에 URL을 넣고 푸시하면 Vercel이 자동 재배포
- `진행` 시트: 분기마다 학생별 현황 갱신 / `제출` 시트: 최종 보고서 한 줄씩 누적
